# Five-minute quick start

1. Extract the archive. Open the macOS app or Windows executable. The default browser opens the observatory.
2. Choose **Past 24 hours**. Select a **Current area of activity**. Notice the visible region boundary and filtered count.
3. Tap a globe marker. Read magnitude, depth and source time. Try the 2D map and event list; selection is shared.
4. Clear the region. Turn **Auto-rotate** on, then select an event. Rotation pauses; **Resume rotation** restarts it deliberately.
5. Choose **Learn → How can an earthquake be deep inside Earth?**. Select section events and compare source depth with epicentre markers. Return to your exploration.
6. Choose **Offline historical demo**. Restart replay, play, pause and seek backward. The timeline, list, globe and exports use the same cumulative cursor.
7. Turn **Country names** on beneath the map. Labels follow the globe and the 2D map, and work independently of plate boundaries. **Copy view link** retains the setting.
8. Export a GeoJSON snapshot, then reopen it. It remains usable without internet access.
9. Select an event and open **Source uncertainty & quality**. Compare the snapshot's values with the current source detail; "Unavailable" is not zero.
10. Show the depth section and edit the **Great-circle transect** — set endpoints by hand or from the selected event, then apply. The corridor is drawn on the globe and travels in the view link.
11. To demonstrate recovery, disconnect internet and refresh a previously loaded recent period. The last good dataset remains with a stale notice. Reconnect and retry. Do not interrupt someone else's connectivity merely to demonstrate this.

Data lives in the operating system's user configuration directory under `HazardAtlas` in `hazard-atlas.db`. The packaged application needs no Go, Node, Python or database installation.

Windows: keep the console window open while using the app; Ctrl+C stops it. macOS: choose **Stop the local server** at the foot of the page when finished.
