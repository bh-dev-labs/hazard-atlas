# Architecture decisions

Country names use persistent SVG text elements between the geography and hazard-marker canvases. Rotation updates their native `x`/`y` coordinates and opacity, without translating cached bitmap textures or snapping label positions. This avoids the extra texture interpolation that changed glyph contrast during subpixel motion. All three layers share the same projection and dimensions. Labels are pointer-transparent, and hazard markers remain above them. Theme or pixel-density changes rebuild label styling.

Run `node scripts/globe-animation-check.mjs` to exercise 480 globe/map frames across desktop and mobile at DPR 1, 2 and 3. The check asserts persistent label elements, constant interior-label opacity during rotation, anchor agreement within 0.02 CSS pixels, no backing-store resets, and working marker selection. It also measures text contrast from actual browser screenshots at eight subpixel positions, comparing native SVG text against the former translated bitmap renderer on a controlled background. Native text must show less contrast variation. This is a browser-rendered regression check, not a guarantee of identical physical display pixels during motion or limb fading.

A single Go process binds to loopback, owns a SQLite cache, and serves embedded production assets. The executable opens the default browser. No runtime Node, Python, remote fonts, tiles, accounts or LLMs are needed. Preact and TypeScript keep view state coordinated; Vite builds the assets. modernc.org/sqlite avoids C toolchains when cross compiling.

The globe uses D3's spherical orthographic projection into Canvas, with real geographic rotation and hemisphere clipping. This is a three-dimensional geographic sphere rendered without WebGL, rather than a perspective terrain mesh. D3 supplies geographic primitives, clipping, distance and graticules; Canvas batches markers. A synchronized equirectangular map uses the same coordinates and data. This deliberately avoids graphics-context and GPU requirements. Natural Earth 110m geography is local and suited to global context, not street-level navigation.

Design follows the supplied image, expressed as CSS custom properties on `:root` rather than literals: ocean, land, ink, paper, panel and accent are named tokens, redefined once under `prefers-color-scheme: dark` and again under `[data-theme="dark"]`. Canvas and SVG cannot resolve `var()`, so `model.ts` exposes `token()`, which reads the resolved values once and caches them until `refreshPalette()` runs on a theme change. System humanist sans fonts avoid network requests. Globe and selection panel dominate; activity regions precede the event table. Depth uses one sequential light-to-dark ramp with text labels, deliberately distinct in hue from the interaction accent so a marker colour never reads as a selection state.

The interface is split into memoised components — `EarthPanel`, `SelectedEvent`, `Replay`, `ActivityAreas`, `EventTable` and `Analysis` — around an `App` that owns the shared state. Callbacks crossing that boundary go through `useStable`, because an inline handler would be a fresh prop on every render and `memo()` would never bail out. That matters most during auto-rotation, which sets camera state every animation frame. Keys are applied where identity matters, and deliberately withheld from the 20,000-mark scatter, where keyed reconciliation costs roughly 280ms per filter change and buys nothing: the marks carry no DOM state.

API datasets are immutable snapshots identified by SHA-256. SQLite stores original JSON, query, retrieval metadata, and transactional event revisions separately from memberships. Live requests coalesce behind a mutex and share a 60-second cache. Historical queries split at the USGS response cap and publish only after completion. Historical snapshots are repeatable observations of a mutable catalog, not a transactional view of USGS.
