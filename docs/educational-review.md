# Educational content review, version 1

All four activities are structured in web/src/content.ts and use the same pinned real USGS snapshot (618 records, February 6–12, 2023, M4+). Source URLs and verification dates are shared with the references page. A source-derived educational explanation is distinguished from an observation and an app calculation.

- Belts: the global dataset contains multiple Pacific-margin regions and non-boundary observations; plate overlay can be switched and region presets compared. No responsible fault is inferred.
- Depth: Tonga candidates include reported depths 10, 35, 90.233, 493.123, 504.722, 582.548, 584.206 and 613.484 km before exact corridor selection. The UI computes exact membership and links plotted points to source records. Surface epicentre and source depth remain distinct.
- Magnitude/intensity: selected record reports magnitude type, felt count and optional intensity values. The comparison widget uses illustrative compatible-scale inputs, not mixed catalog records. Ratios 10 and approximately 31.62 for a one-unit increase have independent tests.
- Sequence: February 6–12 daily UTC counts and Türkiye/Syria regional replay demonstrate temporal clustering. The app does not label the loaded events as aftershocks solely from proximity and does not predict future activity.

Review in this session checked the wording against USGS sources and verified dataset presence and navigation. It is not external expert validation. Full manual keyboard-only completion of every activity and a seismologist review remain publication gates. Reflection prompts are exploratory, without scoring or invented scientific answers.
