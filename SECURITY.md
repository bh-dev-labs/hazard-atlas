# Security policy

## Supported versions

The `main` branch is the supported version. Published archives are reviewed
per release; users should upgrade to the latest release when security fixes
are announced.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository when
available. Do not open a public issue for a suspected vulnerability or include
credentials, private keys, or personal data in a report.

If private reporting is unavailable, contact the repository owner privately
through GitHub with a concise description, affected commit or release, safe
reproduction steps, and the impact. Allow reasonable time for triage and a
fix before public disclosure.

Hazard Atlas is a local loopback application, not a hosted emergency service.
Reports should still include whether the process was started with a custom
data directory, a server-side FIRMS key, or unusual browser/network access.
